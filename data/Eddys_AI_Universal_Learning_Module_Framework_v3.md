# Eddys AI — Universal Learning Module Framework
## Teaching Skeleton for All Module Types

> **Purpose:** Menjadi framework universal untuk merancang seluruh modul pembelajaran Eddys AI.
>
> Framework ini dirancang agar modul terasa seperti **kursus yang benar-benar mengajar**, bukan sekadar halaman berisi materi.
>
> Struktur utamanya dapat digunakan untuk Grammar, Vocabulary, Pronunciation, Speaking, Listening, Reading, Writing, maupun modul kombinasi.

---

# 1. Core Philosophy

Eddys AI harus membawa siswa melalui sebuah **learning journey**, bukan sekadar content delivery.

Prinsip utama:

```text
ORIENT
  ↓
UNDERSTAND
  ↓
EXPLORE
  ↓
LEARN
  ↓
TRY
  ↓
APPLY
  ↓
GET FEEDBACK
  ↓
PRACTICE
  ↓
EVALUATE
```

Atau secara sederhana:

> **Know what → Understand why → Learn how → See examples → Try → Apply**

---

# 2. Dua Fase Utama

Setiap modul memiliki dua fase besar.

```text
MODULE
│
├── PHASE 1
│   THEORY & UNDERSTANDING
│
│   "Saya memahami apa yang dipelajari,
│    bagaimana cara kerjanya, dan kapan
│    menggunakannya."
│
└── PHASE 2
    PRACTICUM & EVALUATION

    "Saya mampu menggunakan apa yang
     sudah dipelajari."
```

## Phase 1

Fokus pada:

- orientation
- concept introduction
- explanation
- structure
- components
- usage
- examples
- contextual understanding
- common mistakes
- guided practice
- readiness

## Phase 2

Fokus pada:

- realistic tasks
- AI interaction
- independent practice
- feedback
- retry
- evaluation
- improvement

---

# 3. Masalah yang Harus Dihindari

## ❌ Content Dump

```text
Judul
↓
Definisi
↓
Tabel
↓
Aturan
↓
Vocabulary
↓
Dialogue
↓
Quiz
```

Walaupun informasinya benar, siswa belum tentu memahami hubungan antar informasi.

---

## ❌ Practice Too Late

Jangan membuat siswa membaca banyak konsep sebelum pernah mencoba.

```text
Concept 1
Concept 2
Concept 3
Concept 4
Concept 5
        ↓
     Practice
```

---

## ❌ Theory Without Purpose

Jangan hanya menjelaskan:

> "Ini adalah struktur X."

Siswa juga perlu mengetahui:

> "Apa itu X?"
>
> "Kenapa X digunakan?"
>
> "Kapan X digunakan?"
>
> "Apa saja bagian X?"
>
> "Bagaimana cara menggunakannya?"

---

# 4. Universal Teaching Skeleton

Ini adalah struktur inti yang dapat digunakan untuk semua jenis modul.

```text
01. MODULE ORIENTATION
02. LEARNING MAP
03. WHAT IS IT?
04. WHY DOES IT MATTER?
05. WHAT DOES IT INCLUDE?
06. HOW DOES IT WORK?
07. WHEN DO WE USE IT?
08. EXAMPLES
09. FORMS / VARIATIONS

12. COMMON MISTAKES
13. GUIDED PRACTICE
14. APPLICATION
15. MINI TRIAL
16. QUICK REVIEW
17. READY FOR PRACTICUM
```

**Tidak semua section wajib digunakan.**

Framework ini adalah skeleton. Content designer memilih bagian yang relevan.

# 5. Section 01 — Module Orientation

## Tujuan

Sebelum belajar, siswa harus tahu:

- apa topik modul
- kenapa topik penting
- apa yang akan dipelajari
- kemampuan apa yang akan diperoleh

### Template

```text
🎯 WHAT ARE WE LEARNING?

[Module Title]

Pada modul ini kamu akan belajar...

[Short explanation]

Setelah selesai, kamu akan mampu:

✓ Objective 1
✓ Objective 2
✓ Objective 3
```

### Contoh

> Pada modul ini kamu akan belajar cara menggunakan **verb "to be"** untuk memperkenalkan diri, menyebutkan asal, dan menjelaskan identitas seseorang.

# 7. Section 03 — What Is It?

## Tujuan

Menjelaskan **konsep dasar** sebelum membahas aturan yang lebih spesifik.

Pertanyaan yang harus dijawab:

> "Sebenarnya apa yang sedang kita pelajari?"

### Template

```text
🧠 WHAT IS [CONCEPT]?

[Simple definition]

[Simple explanation]

[Basic example]
```

### Prinsip

Gunakan bahasa yang mudah dipahami pemula.

Jangan mulai dengan definisi akademis jika definisi tersebut justru membuat konsep lebih sulit.

---

# 8. Section 04 — Why Does It Matter?

## Tujuan

Menjelaskan fungsi dan alasan siswa perlu mempelajari konsep tersebut.

### Template

```text
❓ WHY DO WE LEARN THIS?

We use [concept] when we want to...

• Purpose 1
• Purpose 2
• Purpose 3
```

### Contoh

> We use this structure when we want to:
>
> - introduce ourselves
> - describe someone
> - talk about nationality
> - ask about someone's origin

### Prinsip

Siswa harus memahami:

> "Oh, ternyata konsep ini berguna untuk situasi X."

---

# 9. Section 05 — What Does It Include?

## Tujuan

Menjelaskan **komponen, jenis, bagian, atau cakupan** dari konsep.

Ini sangat penting untuk materi yang memiliki banyak sub-komponen.

### Contoh

Jika topiknya **Pronunciation**:

```text
PRONUNCIATION
│
├── Individual Sounds
├── Vowels
├── Consonants
├── Word Stress
├── Sentence Stress
├── Intonation
├── Rhythm
└── Connected Speech
```

Jika topiknya **To Be**:

```text
TO BE
│
├── AM
├── IS
└── ARE
```

Jika topiknya **Writing**:

```text
WRITING
│
├── Ideas
├── Structure
├── Vocabulary
├── Grammar
└── Revision
```

### Prinsip

Siswa mendapatkan **big picture** sebelum mempelajari detail.

# 10. Section 06 — How Does It Work?

## Tujuan

Menjelaskan mekanisme atau pola.

Bisa berupa:

- formula
- sentence structure
- process
- steps
- pattern
- rule
- workflow

### Template

```text
🧱 HOW DOES IT WORK?

Pattern:

[Pattern]

Example:

[Example]

Breakdown:

[Part 1]
[Part 2]
[Part 3]
```

### Contoh

```text
Subject + Verb + Object

She + reads + a book.
```

Kemudian pecah:

```text
She       → Subject
reads     → Verb
a book    → Object
```

Use [concept] when...

Jangan hanya menjelaskan **apa aturan**, tetapi **kapan aturan tersebut relevan**.

# 12. Section 08 — Examples

## Tujuan

Mengubah teori abstrak menjadi sesuatu yang dapat dilihat.

Gunakan progression:

```text
Simple
↓
Contextual
↓
Applied
```

### Example 1 — Simple

> She is a teacher.

### Example 2 — Contextual

> She is a teacher at my school.

### Example 3 — Applied

> My English teacher is from Australia.

### Prinsip

Tidak perlu membuat banyak contoh hanya untuk memenuhi jumlah.

Contoh harus menjelaskan konsep.

# 15. Section 11 — Contextual Analysis

## Tujuan

Menghubungkan teori dengan penggunaan nyata.

Gunakan:

- dialogue
- reading
- listening
- scenario
- conversation
- sample writing

### Template

```text
🔍 LET'S ANALYZE

[Context]

"[Sentence]"

What can we learn from this?

[Explanation]
```

### Contoh

> "I'm from Spain."

Analisis:

```text
I'm
↓
I am
↓
To Be

from
↓
Shows origin

Spain
↓
Country
```

Dengan demikian siswa melihat bahwa beberapa konsep dapat bekerja bersama dalam satu kalimat.

---

# 16. Section 12 — Common Mistakes

## Tujuan

Menjelaskan kesalahan yang paling mungkin dilakukan siswa.

### Template

```text
🚨 COMMON MISTAKE

❌ Incorrect:
[Sentence]

✅ Correct:
[Sentence]

Why?

[Explanation]
```

### Contoh

```text
❌ She are from Japan.

✅ She is from Japan.

Why?

She → is
```

### Prinsip

Jangan hanya menunjukkan kesalahan.

Jelaskan **mengapa salah**.

---

# 17. Section 13 — Guided Practice

## Tujuan

Siswa mulai menggunakan konsep dengan bantuan.

### Bentuk

- multiple choice
- fill in the blank
- matching
- reorder
- spot the mistake
- sentence completion
- guided speaking
- guided writing

### Flow

```text
Question
↓
Student Answer
↓
Feedback
↓
Explanation
↓
Try Again
```

### Feedback benar

> ✅ Correct!
>
> We use **is** with **she**.

### Feedback salah

> ❌ Not quite.
>
> Remember:
>
> **She → is**
>
> Try again.

---

# 18. Section 14 — Application

## Tujuan

Menggabungkan beberapa konsep.

Bentuk:

- complete a dialogue
- answer a situation
- create a sentence
- respond to a prompt
- summarize
- describe something
- roleplay

### Progressive Support

```text
High Support
↓
Medium Support
↓
Low Support
```

Contoh:

```text
Where are you from?

Hint:
"I'm from ______."
```

Kemudian:

```text
Where are you from?

[No hint]
```

# 25. AI Interaction

Eddys dapat melakukan:

- conversation
- roleplay
- questioning
- correction
- follow-up question
- adaptive difficulty

Contoh:

```text
Eddys:
Hi! Nice to meet you.
Where are you from?

Student:
I'm from Indonesia.

Eddys:
Nice!
What is your nationality?
```

AI harus dapat melanjutkan berdasarkan jawaban siswa.

---

# 26. Independent Practice

Setelah guided practice:

- hilangkan hint
- kurangi sentence starter
- gunakan scenario baru
- minta siswa menghasilkan respons sendiri

### Difficulty

```text
Guided
↓
Semi-guided
↓
Independent
```

# 27. Feedback

Feedback harus spesifik.

### Template

```text
What you did well
✓ ...

What to improve
△ ...

How to improve
→ ...

Try again
[ Retry ]
```

Kategori dapat berupa:

- Grammar
- Vocabulary
- Pronunciation
- Fluency
- Accuracy
- Comprehension
- Task Completion

Gunakan hanya kategori yang relevan dengan modul.

---

# 28. Revision / Retry

Jika memungkinkan, siswa harus mendapatkan kesempatan memperbaiki.

```text
Attempt
↓
Feedback
↓
Revision
↓
Retry
↓
Improvement
```

Tujuan evaluasi bukan sekadar menghasilkan skor.

Tujuan utamanya:

> **Learning through correction.**

---

# 29. Evaluation

Evaluasi harus berdasarkan objective yang diberikan di awal.

Contoh:

```text
Objective:
Use the target structure correctly.

Evaluate:

✓ Accuracy
✓ Sentence formation
✓ Appropriate usage
```

Jangan menilai hal yang tidak diajarkan atau tidak dilatih.

# 30. Role of AI Tutor

AI tidak harus muncul di setiap section.

Gunakan AI ketika AI memberikan nilai tambah.

## Phase 1

AI dapat:

- memberikan hint
- menjelaskan ulang
- memberi contoh tambahan
- membantu siswa yang kesulitan
- memberi feedback
- mengevaluasi mini trial

## Phase 2

AI dapat:

- melakukan conversation
- roleplay
- adaptive questioning
- real-time correction
- speaking feedback
- writing feedback
- difficulty adjustment

# 31. Adaptive Explanation

Jika siswa salah berkali-kali:

```text
Wrong Answer
↓
Detect likely misunderstanding
↓
Simplify explanation
↓
Give easier example
↓
Give simpler question
↓
Try original question again
```

Contoh:

```text
Student:
They is from Spain. ❌

Eddys:
Let's make it easier.

Which is correct?

A. They is
B. They are

Student:
They are.

Eddys:
Exactly!

Now try the original sentence again.
```

# 35. Content Depth Principle

Jangan menyamakan:

> "Universal" = "semua modul harus pendek."

Yang diinginkan:

> **Deep but Chunked.**

Artinya teori boleh cukup mendalam, tetapi dipecah menjadi bagian kecil.

Contoh:

```text
Long Theory
     ↓
What is it?
     ↓
Practice
     ↓
Why?
     ↓
Practice
     ↓
How?
     ↓
Practice
```

Bukan:

```text
Long Theory
↓
Long Theory
↓
Long Theory
↓
Quiz
```

# 36. UX Principle

Setiap section harus memiliki satu tujuan utama.

```text
SECTION
│
├── Title
├── Explanation
├── Example
└── Interaction
```

Tidak semua section harus memiliki interaction jika memang tidak relevan.

---

# 37. Progressive Disclosure

Jika materi cukup kompleks, jangan tampilkan semuanya sekaligus.

Gunakan:

- expandable explanation
- accordion
- step-by-step
- tabs
- examples
- "Show more"
- contextual hints

Tujuannya mengurangi cognitive load tanpa mengurangi kedalaman materi.

# 41. Definition of Done — Phase 1

Sebuah Phase 1 dianggap siap jika:

## Orientation

- [ ] Siswa tahu apa yang akan dipelajari
- [ ] Siswa tahu kenapa topik penting
- [ ] Learning objectives jelas
- [ ] Learning Map tersedia jika materi memiliki beberapa sub-konsep

## Theory

- [ ] Konsep utama dijelaskan
- [ ] Definisi mudah dipahami
- [ ] Purpose / "why" dijelaskan
- [ ] Komponen / cakupan dijelaskan jika relevan
- [ ] Struktur / pattern dijelaskan jika relevan
- [ ] Use cases dijelaskan
- [ ] Contoh tersedia
- [ ] Variasi / forms dijelaskan jika relevan

## Understanding

- [ ] Context tersedia
- [ ] Ada contextual analysis
- [ ] Common mistakes tersedia jika relevan
- [ ] Vocabulary / expressions tersedia jika dibutuhkan

## Practice

- [ ] Ada guided practice
- [ ] Feedback tersedia
- [ ] Ada application
- [ ] Ada mini trial
- [ ] Ada quick review
- [ ] Siswa tahu kapan mereka siap masuk Phase 2

## UX

- [ ] Tidak ada wall of text
- [ ] Section memiliki satu tujuan
- [ ] Informasi kompleks dipecah
- [ ] Progress terlihat
- [ ] Learning Map mudah dipahami
- [ ] Interaksi muncul setelah konsep yang relevan

# 43. Final Design Principle

Jika hanya satu prinsip yang harus diingat ketika membuat modul:

> ## **Don't design a module as a page. Design it as a learning journey.**

Siswa tidak seharusnya merasa:

> "Saya harus membaca halaman ini sampai selesai."

Siswa seharusnya merasa:

> "Saya tahu apa yang sedang saya pelajari."
>
> "Saya tahu kenapa ini penting."
>
> "Saya tahu konsepnya."
>
> "Saya tahu bagian-bagiannya."
>
> "Saya tahu cara menggunakannya."
>
> "Saya sudah mencoba."
>
> "Saya mendapat feedback."
>
> "Sekarang saya siap praktik."
