# Eddys AI — Universal Interactive Learning Module Framework
## Multimodal & Interactive Teaching System

> **Purpose:** Menjadi guideline universal untuk merancang modul pembelajaran Eddys AI yang tidak terasa seperti halaman dokumentasi, tetapi seperti pengalaman kursus interaktif.
>
> Framework ini dapat digunakan untuk Grammar, Vocabulary, Pronunciation, Speaking, Listening, Reading, Writing, maupun modul kombinasi.

---

# 1. Core Idea

Masalah utama modul pembelajaran yang terlalu text-heavy:

```text
Read
↓
Read
↓
Read
↓
Read
↓
Practice
```

Siswa mudah kehilangan fokus karena terlalu lama menerima informasi secara pasif.

Eddys AI harus menggunakan pola:

```text
TEACH
↓
SHOW
↓
LET ME TRY
↓
FEEDBACK
↓
APPLY
```

Dan secara keseluruhan:

```text
ORIENT
↓
UNDERSTAND
↓
EXPLORE
↓
SEE
↓
TRY
↓
APPLY
↓
GET FEEDBACK
↓
PRACTICE
↓
PERFORM
```

# 2. Learning Experience Principle

## Jangan hanya menyampaikan materi.

Materi harus membantu siswa:

> "Saya tahu apa yang saya pelajari."
>
> "Saya tahu kenapa ini penting."
>
> "Saya bisa melihat konsepnya."
>
> "Saya bisa mencoba."
>
> "Saya tahu kesalahan saya."
>
> "Saya bisa memperbaikinya."
>
> "Saya bisa menggunakannya sendiri."

# 3. Universal Module Architecture

Setiap modul memiliki dua fase:

```text
MODULE
│
├── PHASE 1
│   THEORY & UNDERSTANDING
│
│   Orient
│   Understand
│   Explore
│   Practice
│
└── PHASE 2
    PRACTICUM & EVALUATION

    Apply
    Interact
    Perform
    Improve
    Evaluate
```

Phase 1 bukan sekadar "teori".

Phase 1 harus menjadi:

> **Interactive Learning Experience**

# 5. Learning Rhythm

## Hindari terlalu banyak section text-heavy secara berurutan.

### ❌ Bad Rhythm

```text
Text
↓
Text
↓
Text
↓
Text
↓
Text
↓
Practice
```

### ✅ Recommended Rhythm

```text
Text
↓
Visual
↓
Interaction
↓
Text
↓
Example
↓
Micro Practice
↓
Audio / Context
↓
Interaction
↓
Application
```

## Rule of Thumb

Setelah sekitar 2–3 section yang membutuhkan membaca/berpikir, berikan salah satu:

- visual
- interaction
- audio
- micro-practice
- contextual activity
- short reflection

Tujuannya bukan memotong materi secara paksa, tetapi menjaga **learning rhythm**.

# 6. Section 01 — Module Orientation

Siswa harus memahami:

- apa topiknya
- kenapa penting
- kemampuan apa yang akan diperoleh
- apa yang akan dipelajari

### Template

```text
🎯 WHAT ARE WE LEARNING?

[Module Title]

[Short contextual introduction]

By the end of this module, you will be able to:

✓ Objective 1
✓ Objective 2
✓ Objective 3
```

Jangan membuat introduction terlalu panjang.

# 7. Section 02 — Learning Map

Learning Map memberikan gambaran besar sebelum siswa mulai.

### Template

```text
        ↓

        ↓

        ↓
04. [Application]
        ↓
```

```text

✓ Concept

○ Application
○ Practicum
```

# 8. Section 03 — What Is It?

Jawab pertanyaan:

Gunakan:


## 13.1 Concept Diagram

Contoh:

```text

                   │
        ┌──────────┼──────────┐
        ↓          ↓          ↓
       AM         IS         ARE
        │          │          │
        I      He/She/It   You/We/They
```

---

## 13.2 Sentence Breakdown

```text
┌────────┐   ┌────────┐   ┌──────────────┐
│  SHE   │ + │  IS    │ + │ FROM JAPAN   │
│SUBJECT │   │ TO BE  │   │ INFORMATION  │
└────────┘   └────────┘   └──────────────┘
```

Setiap bagian dapat dibuat clickable.

Ketika diklik, Eddys menjelaskan bagian tersebut.

---

## 13.3 Before → After

Contoh:

```text
❌ I Indonesian.
       ↓
    + AM
       ↓
✅ I AM Indonesian.
```

Gunakan animasi ringan untuk menunjukkan transformasi jika membantu pemahaman.

# 20. Section 13 — Pattern Discovery

Ini merupakan komponen penting untuk mengurangi passive reading.

Daripada langsung memberitahu pola:

> "Perhatikan penggunaan am/is/are."

Biarkan siswa menemukan pola.

### Example

```text
I'm from Spain.
I'm a student.
She is from Japan.
They are students.
```

### Prompt

> 👀 What do you notice?

Siswa memilih kata atau bagian yang berulang.

Kemudian Eddys menjelaskan:

> You found it!
>
> These sentences use different forms of **to be**.

### Prinsip

```text
Observe
↓
Notice
↓
Hypothesize
↓
Explain
```

Jika konsep cocok untuk discovery learning, gunakan pola ini.

# 22. Section 15 — Micro Practice

Micro practice adalah latihan kecil yang muncul **di tengah pembelajaran**, bukan hanya di akhir.

Contoh:

```text
Choose the correct form:

She ___ from Japan.

[ is ]
[ are ]
[ am ]
```

Setelah jawaban:

```text
✓ Correct!

She → is
```

Micro practice dapat muncul setelah:

- konsep
- visual
- example
- pattern
- common mistake

Tujuannya menjaga siswa tetap aktif.

---

# 23. Section 16 — Guided Application

Setelah memahami konsep, siswa menggunakannya dengan bantuan.

### Example

```text
Build the sentence:

[ She ] [ is ] [ from Japan ]
```

Atau:

```text
Where are you from?

Hint:
"I'm from ______."
```

Bantuan harus dapat dikurangi:

```text
High Support
↓
Medium Support
↓
Low Support
```

```text
↓
```

# 37. Anti-Jenuh Rules

Gunakan beberapa prinsip berikut:

### Rule 1

Jangan membuat lebih dari 2–3 section text-heavy berturut-turut tanpa perubahan aktivitas.

### Rule 2

Jangan menjadikan semua section sebagai card.

Card harus memiliki fungsi.

### Rule 3

Jangan menggunakan animasi hanya sebagai dekorasi.

### Rule 4

Jangan menggunakan gambar jika gambar tidak membantu pemahaman.

### Rule 5

Jangan membuat interaction hanya untuk terlihat "interaktif".

Interaction harus memiliki tujuan belajar.

### Rule 6

Jangan membuat semua latihan menjadi multiple choice.

Variasikan:

- select
- reorder
- matching
- build
- speak
- listen
- write
- identify
- correct
- explain

# 45. Visual & Interaction Priority

Ketika menentukan apakah sebuah section perlu visual/interaksi, gunakan pertanyaan:

### 1. Apakah konsep lebih mudah dipahami jika dilihat?

→ Gunakan visual.

### 2. Apakah siswa perlu menemukan pola?

→ Gunakan interaction.

### 3. Apakah pronunciation/listening terlibat?

→ Gunakan audio.

### 4. Apakah siswa perlu menghasilkan bahasa?

→ Gunakan input/speaking/writing.

### 5. Apakah AI memberikan feedback yang bernilai?

→ Gunakan AI interaction.

Jika jawabannya tidak, text sederhana mungkin sudah cukup.

# 46. Definition of Done — Interactive Phase 1

## Learning

- [ ] Siswa tahu apa yang akan dipelajari
- [ ] Learning objectives jelas
- [ ] Learning Map tersedia
- [ ] Konsep dijelaskan
- [ ] Purpose dijelaskan
- [ ] Cakupan konsep dijelaskan jika relevan
- [ ] Struktur/pola dijelaskan jika relevan
- [ ] Use cases dijelaskan
- [ ] Contoh tersedia
- [ ] Context tersedia
- [ ] Common mistakes tersedia jika relevan

## Engagement

- [ ] Tidak terlalu banyak text-heavy section berturut-turut
- [ ] Ada visual jika membantu pemahaman
- [ ] Ada micro-practice
- [ ] Ada interaction jika konsep cocok untuk discovery
- [ ] Audio digunakan jika relevan
- [ ] Animasi hanya digunakan jika membantu penjelasan
- [ ] Tidak ada decorative interaction yang tidak memiliki tujuan belajar

## Practice

- [ ] Guided practice tersedia
- [ ] Application tersedia
- [ ] Mini Trial tersedia
- [ ] Feedback tersedia
- [ ] Retry tersedia jika relevan
- [ ] Quick Review tersedia

## UX

- [ ] Progress menunjukkan learning state
- [ ] Cognitive load terkontrol
- [ ] Progressive disclosure digunakan untuk informasi kompleks
- [ ] User tahu posisi mereka dalam learning journey
- [ ] CTA menuju Phase 2 jelas

# 47. Definition of Done — Phase 2

- [ ] Task jelas
- [ ] Objective jelas
- [ ] Guided practice tersedia jika dibutuhkan
- [ ] AI interaction tersedia jika relevan
- [ ] Independent practice tersedia
- [ ] Feedback spesifik
- [ ] Retry/revision tersedia
- [ ] Evaluation sesuai objective
- [ ] Result mudah dipahami
- [ ] Improvement direction diberikan

## Prinsip terakhir

> **Don't design a module as a page.**
>
> **Design it as a learning experience.**

Eddys AI seharusnya membuat siswa merasa:

> "Gue ngerti apa yang sedang dipelajari."
>
> "Gue bisa lihat cara kerjanya."
>
> "Gue bisa coba sekarang."
>
> "Gue tahu kenapa jawaban gue salah."
>
> "Gue bisa memperbaikinya."
>
> "Sekarang gue siap ngomong / nulis / mendengarkan / menggunakan bahasa itu."
