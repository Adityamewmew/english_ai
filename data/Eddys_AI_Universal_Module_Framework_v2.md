# Eddys AI — Universal Module Content & Learning Framework

> **Purpose:** Panduan universal untuk merancang seluruh modul pembelajaran Eddys AI, terutama struktur **Phase 1 — Teori & Pemahaman** dan **Phase 2 — Praktikum & Evaluasi**.
>
> Framework ini **bukan checklist wajib**. Setiap modul memilih section yang relevan berdasarkan jenis materi dan skill yang ingin dilatih.

---

# 1. Filosofi Pembelajaran Eddys AI

Eddys AI bukan sekadar tempat untuk membaca materi.

Tujuan setiap modul adalah membawa siswa melalui proses:

```text
CONTEXT
   ↓
UNDERSTAND
   ↓
NOTICE
   ↓
LEARN
   ↓
TRY
   ↓
GET FEEDBACK
   ↓
APPLY
   ↓
EVALUATE
```

Prinsip utama:

> **Don't make students read more. Make them understand more.**

Dan:

> **Theory prepares students to use the language. Practice proves that they can use it.**

---

# 2. Struktur Besar Modul

Setiap modul terdiri dari dua fase:

```text
MODULE
│
├── PHASE 1
│   TEORI & PEMAHAMAN
│
│   Tujuan:
│   "Saya memahami konsep dan tahu cara menggunakannya."
│
└── PHASE 2
    PRAKTIKUM & EVALUASI

    Tujuan:
    "Saya mampu menggunakan konsep tersebut dalam situasi nyata."
```

## Phase 1

Fokus:

- memahami konsep
- memahami alasan penggunaan
- mengenali pola
- melihat contoh
- memahami konteks
- mengenali kesalahan
- melakukan latihan terkontrol
- melakukan mini trial

## Phase 2

Fokus:

- menggunakan skill
- berinteraksi dengan AI
- menyelesaikan task
- melakukan praktik mandiri
- menerima feedback
- memperbaiki kesalahan
- dievaluasi

Tidak semua modul harus memiliki semua section.

Gunakan arsitektur berikut sebagai pilihan:

```text
01. Learning Goal
02. Context / Warm-up
03. Discover / Notice
04. Core Concept
05. Why / Purpose
06. Pattern / Structure
07. Usage / When to Use
08. Forms / Variations
09. Examples
10. Key Vocabulary / Expressions
11. Contextual Analysis
12. Common Mistakes
13. Quick Practice
14. Guided Application
15. Mini Trial
16. Quick Review

```

Section dapat:

- digunakan
- digabung
- dihilangkan
- dipindahkan

tergantung kebutuhan modul.

# 5. Section 01 — Learning Goal

## Tujuan

Siswa mengetahui:

1. apa yang akan dipelajari
2. mengapa materi tersebut penting
3. apa yang diharapkan bisa dilakukan setelah selesai

### Template

```text
🎯 What You'll Learn

Pada modul ini kamu akan belajar:

✓ [Objective 1]
✓ [Objective 2]
✓ [Objective 3]
```

### Contoh

> Setelah menyelesaikan modul ini, kamu akan mampu:
>
> - memahami penggunaan konsep utama
> - menggunakan pola dalam kalimat sederhana
> - menerapkan konsep dalam percakapan

### Rule

Maksimal sekitar **3–4 objective utama**.

Gunakan bahasa yang berorientasi pada kemampuan siswa.

### Hindari

> Memahami struktur sintaksis...

### Lebih baik

> Menggunakan struktur tersebut untuk membuat kalimat...

---

# 6. Section 02 — Context / Warm-up

## Tujuan

Memberikan alasan dan situasi nyata sebelum teori diberikan.

Context dapat berupa:

- dialogue
- gambar
- cerita
- pertanyaan
- audio
- video
- scenario
- contoh kalimat
- situasi sehari-hari

### Template

```text
👋 Let's Start

[Short situation]

[Example / Dialogue]

🔊 Listen
```

### Rule

Context tidak perlu panjang.

Siswa cukup memahami:

> "Materi ini digunakan dalam situasi seperti ini."

---

# 7. Section 03 — Discover / Notice

## Tujuan

Mengajak siswa memperhatikan pola sebelum menerima penjelasan.

Contoh:

> Perhatikan kalimat:
>
> **She is from Japan.**
>
> Apa fungsi kata **is**?

Pilihan:

- menunjukkan negara
- menghubungkan subjek dengan informasi
- menunjukkan waktu

Setelah siswa menjawab, berikan feedback.

### Prinsip

Gunakan **guided discovery**.

Tidak masalah jika siswa salah.

Kesalahan menjadi bagian dari pembelajaran.

---

# 8. Section 04 — Core Concept

## Tujuan

Menjelaskan konsep inti dengan bahasa sederhana.

### Template

```text
🧠 Let's Understand

[Definisi sederhana]

[Penjelasan singkat]

[Contoh]
```

### Prinsip

Untuk konsep baru, jawab:

- Apa ini?
- Apa fungsinya?
- Apa yang perlu siswa pahami?

### Contoh

> **To be** adalah kata kerja yang dapat digunakan untuk menghubungkan subjek dengan informasi tentang identitas, keadaan, asal, pekerjaan, atau kondisi.

Kemudian langsung beri contoh.

---

# 9. Section 05 — Why / Purpose

Section ini sangat penting untuk materi yang bersifat teoritis.

## Tujuan

Menjawab:

> "Kenapa saya harus menggunakan bentuk ini?"

Contoh:

### Why do we use this form?

> Kita menggunakan bentuk ini ketika ingin...

Kemudian bandingkan:

```text
Tanpa konsep:
I from Indonesia. ❌

Dengan konsep:
I am from Indonesia. ✅
```

Siswa tidak hanya tahu aturan, tetapi memahami **fungsi aturan tersebut**.

---

# 10. Section 06 — Pattern / Structure

## Tujuan

Memberikan struktur yang bisa digunakan siswa.

### Template

```text
🧱 Basic Pattern

[Formula]

Subject + [X] + [Y]
```

Kemudian pecah:

```text
She | is | from Japan
 ↓     ↓       ↓
 S    Verb   Information
```

### Rule

Formula harus selalu disertai contoh.

Jangan menampilkan formula tanpa konteks.

---

# 11. Section 07 — Usage / When to Use

## Tujuan

Menjelaskan kapan konsep digunakan.

### Template

```text
📌 When do we use it?

1. [Use case]
   Example: ...

2. [Use case]
   Example: ...

3. [Use case]
   Example: ...
```

Tidak harus selalu tiga.

### Contoh kategori penggunaan bahasa

- identity
- location
- nationality
- occupation
- condition
- ability
- past event
- future plan
- comparison
- request
- opinion
- description

Pilih yang relevan dengan materi.

---

# 12. Section 08 — Forms / Variations

Untuk materi yang memiliki bentuk berbeda, jelaskan secara bertahap.

Contoh:

```text
Positive
↓
Negative
↓
Question
↓
Short / Natural Form
```

### Template

```text
Positive:
[Example]

Negative:
[Example]

Question:
[Example]

Natural / Contraction:
[Example]
```

Jangan memasukkan semua variasi jika tidak termasuk scope modul.

# 13. Section 09 — Examples

Setiap teori penting harus memiliki contoh.

Gunakan minimal:

- satu contoh sederhana
- satu contoh kontekstual
- satu contoh yang sedikit lebih kompleks jika diperlukan

### Format

```text
Example 1
[Simple]

Example 2
[Contextual]

Example 3
[Applied]
```

### Prinsip

Contoh harus membantu siswa memahami **penggunaan**, bukan sekadar memperbanyak kalimat.

---

# 14. Section 10 — Key Vocabulary / Expressions

Digunakan untuk:

- vocabulary
- phrase
- expression
- terminology
- pronunciation
- collocation

### Template

```text
WORD / PHRASE

Pronunciation

Meaning

Example:
[Sentence]

🔊 Listen
```

### Prinsip

Vocabulary sebaiknya selalu memiliki konteks.

Kurang baik:

```text
country = negara
```

Lebih baik:

```text
country
= negara

Spain is a beautiful country.
```

# 15. Section 11 — Contextual Analysis

Gunakan dialogue, reading, listening transcript, atau scenario yang telah diperkenalkan sebelumnya.

## Tujuan

Membantu siswa melihat teori bekerja dalam konteks.

### Template

```text
🔍 Let's Analyze

"[Sentence from context]"

What does [keyword] do here?

[Explanation]

Remember:
[Key takeaway]
```

### Contoh

Ambil kalimat dari dialogue:

> "I'm from Spain."

Kemudian analisis:

- `I'm` = `I am`
- `from` menunjukkan asal
- `Spain` adalah country

Dengan demikian satu dialogue dapat menjadi sumber pembelajaran beberapa konsep.

---

# 16. Section 12 — Common Mistakes

Ini adalah section yang sangat penting untuk pemula.

### Template

```text
🚨 Common Mistake

❌ [Incorrect sentence]

✅ [Correct sentence]

Why?

[Simple explanation]
```

### Contoh

```text
❌ She are from Japan.

✅ She is from Japan.

Why?

She → is
```

### Jenis kesalahan yang dapat dimasukkan

- grammar
- word choice
- pronunciation
- word order
- spelling
- article
- tense
- vocabulary usage
- pronunciation transfer
- translation langsung dari bahasa Indonesia

Jangan memasukkan terlalu banyak kesalahan sekaligus.

Pilih kesalahan yang paling relevan dengan objective.

---

# 17. Section 13 — Quick Practice

## Tujuan

Menguji satu konsep yang baru saja dijelaskan.

Latihan harus langsung mengikuti teori.

### Pattern

```text
Concept
↓
Example
↓
Question
↓
Feedback
```

### Bentuk soal

- multiple choice
- fill in the blank
- matching
- reorder
- true/false
- spot the mistake
- select correct sentence

### Contoh

> She ___ from Japan.

```text
[ am ] [ is ] [ are ]
```

### Correct feedback

> ✅ Correct!
>
> We use **is** with **she**.

### Incorrect feedback

> ❌ Not quite.
>
> Remember:
>
> **She → is**
>
> Try again.

Feedback harus menjelaskan **alasan**, bukan sekadar benar/salah.

# 18. Section 14 — Guided Application

Setelah siswa memahami beberapa konsep, gabungkan konsep tersebut.

### Contoh

```text
Concept A + Concept B
```

Bentuk:

- melengkapi dialogue
- menyusun kalimat
- memilih respons
- matching
- short answer
- guided writing
- guided speaking

### Prinsip

Bantuan masih tersedia.

Contoh:

```text
Where ___ you from?

Hint:
Think about the subject "you".
```

# 20. Peran AI Tutor di Phase 1

AI tidak perlu muncul di setiap section.

Gunakan AI ketika memberikan nilai tambah.

## AI cocok untuk:

- memberikan hint
- menjelaskan ulang
- membuat contoh tambahan
- memberikan feedback
- mengevaluasi speaking
- mengevaluasi writing
- menyesuaikan pertanyaan
- membantu siswa yang salah berulang kali

### Contoh

```text
🤖 Eddys

Good attempt!

You correctly used:
✓ "I'm from Indonesia."

Try improving:
"She are from Japan."

Remember:
She → is

Try again.
```

AI harus memberikan feedback yang **spesifik dan actionable**.

# 21. Adaptive Explanation

Jika siswa salah berkali-kali, jangan hanya mengulang soal yang sama.

Eddys dapat:

```text
Student answers incorrectly
        ↓
Identify likely misunderstanding
        ↓
Give simpler explanation
        ↓
Give easier example
        ↓
Ask a simpler question
        ↓
Return to original difficulty
```

Contoh:

```text
Student:
They is from Spain. ❌

Eddys:
Let's make it easier.

Which one sounds correct?

A. They is
B. They are

Student:
They are.

Eddys:
Exactly!

Now try the original sentence again.
```

# 22. Section 16 — Quick Review

Sebelum Phase 2, lakukan review singkat.

Ideal:

- 3–5 soal
- mencakup objective utama
- variasi jenis soal
- tidak terlalu panjang

### Contoh

```text
🧠 Quick Check

1. Choose the correct sentence.
2. Complete the sentence.
3. Fix the mistake.
4. Apply the concept.
5. Answer a short contextual question.
```

Tujuan:

> Mengukur readiness, bukan membuat ujian panjang.

# 33. Aturan Content Design

## Rule 1 — Satu section, satu tujuan

Jangan mencampur terlalu banyak tujuan dalam satu section.

---

## Rule 2 — Context before abstraction

Jika memungkinkan:

```text
Example
→ Explanation
```

bukan:

```text
Definition
→ Definition
→ Definition
→ Example
```

---

## Rule 3 — Theory must answer "why"

Setiap konsep penting idealnya menjawab:

> Apa?
>
> Kenapa?
>
> Kapan?
>
> Bagaimana?

---

## Rule 4 — Theory must have examples

Konsep tanpa contoh sulit dipahami pemula.

---

## Rule 5 — Practice should follow explanation immediately

Jangan membuat siswa membaca 10 konsep sebelum diberi kesempatan mencoba.

---

## Rule 6 — Feedback must teach

Hindari:

> ❌ Wrong.

Gunakan:

> ❌ Not quite.
>
> Remember: **She → is**.
>
> Try again.

---

## Rule 7 — Don't over-gamify

Interaksi harus membantu pembelajaran.

Tidak semua informasi harus menjadi game atau quiz.

---

## Rule 8 — Don't over-explain

Teori boleh mendalam, tetapi dibagi menjadi potongan kecil.

```text
Long explanation
        ↓
Break into
        ↓
Concept A
Practice
Concept B
Practice
Concept C
Practice
```

# 36. Learning Progress

Contoh:

```text
01 Goal        ✓
02 Context     ✓
03 Concept     ✓
04 Practice    ●
05 Application ○
06 Review      ○
```

Atau:

```text
Concept 3 of 6

████████████░░░░░░
```

---

# 37. Content Density

Gunakan prinsip:

> **Deep, but chunked.**

Bukan:

> **Short, but shallow.**

Teori tidak harus selalu sedikit.

Yang penting:

- satu konsep pada satu waktu
- ada contoh
- ada konteks
- ada interaksi
- ada feedback
- ada hubungan dengan konsep berikutnya

Sebuah Phase 1 dianggap siap jika:

### Learning

- [ ] Learning objectives jelas
- [ ] Context tersedia
- [ ] Konsep utama dijelaskan
- [ ] "Why" dijelaskan jika relevan
- [ ] Pattern / structure tersedia jika relevan
- [ ] Use cases tersedia jika relevan
- [ ] Contoh tersedia
- [ ] Common mistakes tersedia jika relevan
- [ ] Vocabulary memiliki konteks
- [ ] Ada latihan setelah konsep
- [ ] Ada feedback
- [ ] Ada contextual application
- [ ] Ada mini trial
- [ ] Ada quick review
- [ ] Siswa memahami tujuan Phase 2

### UX

- [ ] Tidak ada wall of text
- [ ] Section memiliki satu tujuan
- [ ] Informasi penting mudah dipindai
- [ ] Interaksi muncul pada waktu yang tepat
- [ ] Progress terlihat
- [ ] Tidak semua section dipenuhi informasi sekaligus

---

# 39. Definition of Done — Phase 2

- [ ] Task jelas
- [ ] Objective jelas
- [ ] Guided practice tersedia jika dibutuhkan
- [ ] AI interaction berjalan

- [ ] Feedback spesifik
- [ ] Siswa dapat retry / memperbaiki

- [ ] Result mudah dipahami
- [ ] Siswa tahu apa yang perlu diperbaiki

# 41. Final Design Principle

Jika harus memilih satu prinsip untuk semua modul Eddys AI:

> ## **Don't design modules as pages. Design them as learning journeys.**

Siswa tidak seharusnya merasa:

> "Gue harus baca halaman ini sampai habis."

Siswa seharusnya merasa:

> "Gue ngerti konsep ini → gue coba → gue salah → Eddys menjelaskan → gue coba lagi → gue bisa → sekarang gue siap praktik."

Itulah perbedaan antara **content delivery** dan **learning experience**.
